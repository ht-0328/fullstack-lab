- W-1「解決する課題」の最初の段落: 案の「読者は〜」の文は、決まりの更新（W-1。誰のためには先頭の表の想定読者で足りる）で不要なので入れなかった。as-built の旨は状態の行に移し、段落を 4 文に収めた

- W-10「期限日の補足情報は『あれば表示する』情報」の区分: 構成の仮定 9 は「外部サービスはカレンダー API」までで、「あれば表示する」は載っていない。W-10 の「業務環境と無関係の選択は前提と書く」に合わせて、この行は前提のまま根拠を文にし、仮定 9 は「外部サービスは、期限日が営業日か祝日かを返すカレンダー API とする」という仮定の行を別に足した
