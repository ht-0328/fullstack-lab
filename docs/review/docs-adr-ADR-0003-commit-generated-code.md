- W-6「主語を省かず」と、ADR の「決定」を主語なしで言い切る形が合わない。方針を言い切る文では主語の省略を許すのか → 2026-11-01 の決まりの更新で解消（W-6 に「方針を言い切る文（ADR の決定）は主語を省いてよい」を追加）
