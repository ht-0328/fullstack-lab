### 決まり側の課題

- W-5 で、挙げている言い回しを使わずに実装で起きたことを書いた文を、経緯として直させるかがはっきりしない（1 回目）。
- W-4 が理由の参照を認めるのは同じ文書の別の節だけで、ADR から設計書の節へのリンクで理由に代えてよいかが書かれていない（1 回目）。
- ADR の状態の行の型がテンプレートに無く、採用のときに「誰が」「なぜ」を書くかが ADR によって分かれている。テンプレートに書き方の例を 1 つ足す（1 回目、2 回目）。
- ADR から設計書の「実装の段取り」の番号を指すと、設計書を直したときに指す中身が変わる。ADR から段取りの番号を指さない決まりがあるとよい（1 回目）。
- W-2 の「初出がセルなら括弧書き」を、先頭の表のセルにも当てはめるか。差分評価で、直した結果として初出がセルへ移った語を拾うか（1 回目、2 回目）。
- W-2 の括弧書きで説明すると、セルがもともと括弧の中にあるとき括弧が 3 重になる。「括弧書きの中で初出になる語は、表のリードか前の文で前出しする」と足す（3 回目）。
