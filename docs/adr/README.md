この文書は、決定の記録（ADR。Architecture Decision Record）の索引で、今ある ADR を一覧にします。ADR は、設計書 1 本（変更 1 件）の中で閉じず、他の変更にも従わせたい方針を、その理由とともに方針 1 件につき 1 本で記録する文書です。設計書との使い分けは docs の README の[「設計書と ADR の使い分け」](../README.md#設計書と-adr-の使い分け)、節構成と書き方の例は [ADR のテンプレート](TEMPLATE.md)、書き方の決まりは docs の README の[「書き方」](../README.md#書き方人が読める文書にする決まり)にあります。

方針を覆すときは、作成者（文書を書き、方針を決める人。ht-0328）が新しい ADR を書き、古い ADR の状態を「廃止（ADR-NNNN で置き換え）」にします。古い ADR の決定の中身は変えません（読みやすさの修正は可）。ADR は「なぜその方針にしたか」に答える記録なので、決めた当時の判断と理由を後から読めるように残すためです。
