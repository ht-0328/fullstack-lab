# エラー応答

この文書は、認証 API（[全体像](README.md)）のエラー応答を記す。認証 API は、Keycloak（一般利用者のログインを受け付けてトークンを発行するサービス。[用語](../../architecture/README.md#用語)）を呼んで処理するので、エラーには Keycloak の失敗を変換したものが含まれる。この文書では、Keycloak に登録されたアカウントを「Keycloak のユーザー」と書く。

## エラーの形

エラーは、どれも RFC 9457 の Problem Details（エラーの種類、ステータスコード、説明の `detail` などを JSON で返す標準の形。`application/problem+json`）で返す。認証 API は、Keycloak の応答の本文を呼び出し元に出さない。

## ステータスコードごとの条件

次の表は、ステータスコードごとの条件を示す。Keycloak の失敗による 400、502、503 と、内部の失敗による 500 は、どのエンドポイントでも起こる。

| ステータスコード | 条件 |
|---|---|
| 400 | 入力が契約（領域同士の API の取り決め。[用語](../../architecture/README.md#用語)）の決まりに合わない。または、Keycloak が入力を拒んで 400 を返した（`detail` は `入力が受け付けられませんでした`） |
| 403 | パスワード変更で、現在のパスワードが違う（`detail` は `現在のパスワードが違います`） |
| 404 | 参照かパスワード変更で、ID の Keycloak のユーザーが無い |
| 409 | 登録で、メールアドレスが登録済み（`detail` は `このメールアドレスは登録済みです`） |
| 500 | 想定していない内部の失敗。Keycloak の応答に、あるはずの `Location` ヘッダーや本文が無いときが当たる |
| 502 | Keycloak が、この表の 400、403、404、409 の行のどれにも当たらない 4xx か 5xx を返した。Keycloak の 5xx、サービスアカウント（クライアント自身の権限でトークンを得る仕組み）の権限の不足、クライアントシークレットの誤りが当たる（`detail` は `unexpected response from identity provider`） |
| 503 | Keycloak に接続できない、または応答がタイムアウトした（`detail` は `identity provider unavailable`） |

エンドポイントごとの処理は、[アカウントの登録](customer-signup.md)、[アカウントの参照](customer-get.md)、[パスワードの変更](password-change.md) にある。登録の途中で Keycloak の呼び出しが失敗したときの後始末も登録の文書にあり、返すエラーはこの表のとおりである。入力の決まりは契約 [auth.yaml](../../../auth/openapi/auth.yaml) にある。

## ログに出す内容

認証 API は、502 のときは Keycloak のステータスコードだけを、503 のときは接続の失敗の内容をログに記録する。メールアドレスとパスワードは、ログにも例外のメッセージにも出さない。
