# タスク一覧の画面（`/`）

この文書は、タスクの一覧を出す画面を記す。画面は `web/frontend/app/pages/index.vue` にあり、URL は `/` である。一般利用者には自分のタスクだけ、社員には全件が出る。画面の見本は [タスク一覧の見本](screens/task-list.html) にある。

このフォルダの全体と、使う語の意味は [BFF と画面の全体像](README.md) にある。

## データの取得

画面は、初回の表示のときに SSR（Nuxt のサーバーが HTML を作る描画）で `GET /bff/tasks` を呼ぶ。だれのタスクを返すかは BFF（画面専用のサーバー側 API。[用語](../../architecture/README.md#用語)）が決め、画面は絞り込まない（[タスクの一覧（`GET /bff/tasks`）](task-list.md)）。ログイン中の利用者は `useMe`（[画面から BFF を呼ぶ共通部品](nuxt-bff-client.md)）で取る。

## 表示

次の表は、画面に出すものと条件を示す。

| 表示するもの | 条件と中身 |
|---|---|
| 見出し | 社員は「すべてのタスク」、一般利用者は「あなたのタスク」 |
| 「＋ タスクを登録」のリンク | `capabilities.canCreateTask` が true のときだけ出す。移動先は `/tasks/new` |
| 表 | 列は ID、タイトル、期限、状態で、社員にはさらに登録者を出す。タイトルは詳細（`/tasks/{id}`）へのリンク |
| 期限 | 期限日が無ければ「-」 |
| 状態 | 完了日時があれば「完了」、無ければ「未完了」。完了したタスクも隠さない |
| 「タスクはまだありません。」 | タスクが 0 件のとき、表の代わりに出す |
| 「一覧を取得できませんでした（ステータスコード）」 | BFF がエラーを返したとき、表の代わりに出す |

## テスト

次の表は、この画面について確かめることを示す。Playwright は、ブラウザを操作して画面を確かめるテストである。

| 層 | 場所 | 確かめること |
|---|---|---|
| Playwright | `web/e2e/tests/tasks.spec.ts` | 登録したタスクが一覧に出ること。他の一般利用者のタスクが一覧に出ないこと。`task-viewer` の社員には見出し「すべてのタスク」が出て、「＋ タスクを登録」が出ず、その社員が一般利用者のタスクの詳細を開けること。完了にしたタスクの状態が「完了」になること |
