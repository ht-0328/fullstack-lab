表示

  • 見出しは、一般利用者なら「あなたのタスク」、社員なら「すべてのタスク」
  • 列は ID、タイトル、期限、状態。社員にだけ「登録者」の列を足す
  • 期限が無いタスクは「-」
  • 完了したタスクも隠さず、状態の列で見分ける
  • 1 件も無いときは「タスクはまだありません。」

操作

  • 「＋ タスクを登録」でタスク登録へ。登録できる人（一般利用者と task-admin の社員）にだけ出す
  • タイトルを押すとタスク詳細へ

うまくいかないとき

  • 一覧を取れなかったら「一覧を取得できませんでした（ステータスコード）」
