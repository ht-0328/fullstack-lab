パスワード変更

一般利用者が自分のパスワードを変える画面です。上の帯の「パスワード変更」から開きます。社員には、このリンクを出しません。

http://localhost/me/password

パスワード変更

← 一覧へ戻る

入力

  • 現在のパスワード: 必須
  • 新しいパスワード: 必須、8〜128 文字
  • 新しいパスワード（確認）: 必須

操作

  • 「変更」を押すと PUT /bff/me/password を呼ぶ
  • 成功したら、入力欄の代わりに「変更しました。次回から新しいパスワードでログインしてください。」と出す

うまくいかないとき

  • 変更できなかったら（例: 現在のパスワードが違う）、ボタンの下に赤い字で理由を出す
