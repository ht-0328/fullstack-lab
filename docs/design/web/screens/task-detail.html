表示

  • 見出しはタスクのタイトル
  • 説明と期限日は、無ければ「-」
  • 状態は「未完了」か「完了（完了日時）」

「期限日の補足（外部サービス）」の行

  • 取れたとき: 「営業日」か「休日（祝日の名前）」
  • 外部サービスから取れなかったとき: 赤い字で「現在取得できません」。ほかの行はそのまま出す
  • 期限日が無いとき: 「期限日なし」

操作

  • 「完了にする」を押すと POST /bff/tasks/{id}/complete を呼び、状態が「完了（完了日時）」に変わる
  • 「完了にする」は、完了にできる人（登録した本人と task-admin の社員）が未完了のタスクを開いたときにだけ出す

うまくいかないとき

  • タスクが無い、または見る権限が無いタスクなら「タスクが見つかりません」
  • それ以外で取れなかったら「タスクを取得できませんでした（ステータスコード）」
  • 完了にできなかったら、ボタンの下に赤い字で理由を出す
