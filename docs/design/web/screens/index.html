画面のイメージ

fullstack-lab-web の 5 つの画面を、画面ごとに 1 ページずつ、実際の画面と同じ項目と文言で描いたものです。動きません（ボタンを押しても送信しません）。画面の中のリンクを押すと、遷移先の画面のページへ移ります。

画面の一覧と遷移

会員登録/signup 登録後にログイン → タスク一覧/ 「＋ タスクを登録」 → タスク登録/tasks/new 登録に成功 → タスク詳細/tasks/{id}
タスク一覧/ タイトルを押す → タスク詳細/tasks/{id} 　　どの画面でも、上の「パスワード変更」 → パスワード変更/me/password
画面URL使える人呼ぶ BFF
タスク一覧/一般利用者、社員GET /bff/tasks
タスク登録/tasks/new一般利用者、社員（task-admin）POST /bff/tasks
タスク詳細/tasks/{id}一般利用者（自分のタスクだけ）、社員GET /bff/tasks/{id}、POST /bff/tasks/{id}/complete
会員登録/signupログインしていない人POST /bff/signup
パスワード変更/me/password一般利用者PUT /bff/me/password

どの画面も、上の帯（名前、ロール、リンク）を出すために GET /bff/me を呼びます。
