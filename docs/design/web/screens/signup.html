会員登録

一般利用者が自分でアカウントを作る画面です。5 つの画面のうち、これだけがログインせずに開けます。

入力するとき

http://localhost/signup
fullstack-lab マイページ 未認証 ログイン

会員登録

すでに登録済みの方は ログイン へ。

登録できたあと

http://localhost/signup
fullstack-lab マイページ 未認証 ログイン

会員登録

登録しました（carol@example.com）。登録したメールアドレスとパスワードでログインしてください。

ログインする

入力

  • メールアドレス: 必須、254 文字まで。ログイン ID を兼ねる
  • 姓、名: 必須、それぞれ 50 文字まで
  • パスワード: 必須、8〜128 文字

操作

  • 「登録」を押すと POST /bff/signup を呼ぶ
  • 成功したら、同じ画面のまま「登録しました」と「ログインする」のリンクに切り替わる
  • 「ログイン」「ログインする」を押すと Keycloak のログイン画面へ移り、ログイン後はタスク一覧を開く

うまくいかないとき

  • 登録できなかったら（例: 同じメールアドレスが登録済み）、ボタンの下に赤い字で理由を出す
  • 社員が開いたら、入力欄を出さず「社員のアカウントは IdP 側で管理します。この画面は一般利用者向けです。」と出す
